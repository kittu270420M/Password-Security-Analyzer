    About

    How this analyzer works

    1. Password Strength Scoring

    The score (0–100) starts from the estimated entropy and is then reduced for patterns attackers try first: common passwords, keyboard or numeric sequences, repeated characters, years, and predictable “Word + symbol + digits” structures. Very short passwords are capped. 80+ is Strong, 50–79 Moderate, below 50 Weak.

    2. Entropy Estimation

    Entropy = length × log2(character pool size). The pool is the sum of the character classes you used (26 upper, 26 lower, 10 digits, 32 symbols). This assumes every character is picked uniformly at random, so it can overestimate the unpredictability of human-created passwords.

    3. Crack-Time Estimation

    Average guesses = NL / 2, divided by an assumed 10 billion guesses per second. The result is theoretical. Real cracking time depends on the attack scenario, hashing algorithm, hardware, and guessing rate. It is never a guarantee. Huge values are computed with logarithms to avoid number overflow.

    4. Privacy by Design

    All analysis runs locally in your browser. There is no backend, database, or external API, and your password is never stored or transmitted. The PDF report is generated in the browser and never contains the password itself. Only your theme choice is saved in localStorage.

    5. Password Generator Methodology

    Passwords are built with crypto.getRandomValues() using rejection sampling to avoid modulo bias. When the length allows, at least one character from each selected category is included, and the result is shuffled with a secure Fisher–Yates shuffle. Math.random() is never used.

    6. Security Limitations

    This tool does not check real data breaches or leaked-password databases, and its common-password list is small. A high score does not make a password safe if it was reused or leaked. Use a unique password for every account and enable multi-factor authentication.
